# BentoDev 🚀

### Tu aprendizaje, tus proyectos y tu evolución como desarrollador.

BentoDev es una plataforma didáctica de portafolios digitales que permite a los desarrolladores documentar, organizar y presentar sus proyectos mediante una interfaz visual basada en el diseño **Bento Grid**.

El objetivo es que cada persona pueda mostrar no solo qué ha desarrollado, sino también cómo lo hizo, qué tecnologías utilizó, qué conocimientos aplicó y cuánto tiempo dedicó a su aprendizaje.

La plataforma integrará herramientas de inteligencia artificial para generar resúmenes de los proyectos y relacionar las experiencias prácticas con los cursos y módulos formativos correspondientes.

> **Estado del proyecto:** Planificación y desarrollo inicial.

---

## 🎯 Objetivos del proyecto

- Crear un portafolio digital personalizable y visualmente atractivo.
- Presentar proyectos mediante tarjetas organizadas en una cuadrícula Bento.
- Documentar el proceso de desarrollo y las decisiones técnicas.
- Relacionar los proyectos con las tecnologías y los módulos de aprendizaje.
- Registrar el tiempo dedicado a las actividades.
- Utilizar inteligencia artificial para generar resúmenes de aprendizaje.
- Practicar un flujo de desarrollo profesional utilizando Git, GitHub y Pull Requests.
- Construir una aplicación Fullstack con tecnologías utilizadas en el desarrollo web empresarial.

---

## ✨ Funcionalidades planificadas

### 1. Perfil del desarrollador

Cada usuario podrá crear un perfil profesional con:

- Nombre y fotografía o avatar.
- Biografía y presentación personal.
- Tecnologías y herramientas que utiliza.
- Cursos y módulos formativos completados.
- Enlaces a GitHub, LinkedIn y otros recursos profesionales.

### 2. Portafolio Bento Grid

Los proyectos se presentarán mediante tarjetas de diferentes tamaños.

Cada tarjeta podrá incluir:

- Imagen representativa.
- Nombre del proyecto.
- Descripción breve.
- Tecnologías utilizadas.
- Enlace al detalle del proyecto.

El diseño deberá ser responsive para adaptarse a computadoras, tabletas y teléfonos.

### 3. Detalle del proyecto

Cada proyecto tendrá una página de documentación que permitirá explicar:

- Problema que se buscaba resolver.
- Objetivos y alcance.
- Solución implementada.
- Tecnologías y arquitectura utilizadas.
- Etapas del desarrollo.
- Dificultades encontradas y cómo se resolvieron.
- Casos de prueba y resultados.
- Capturas de pantalla.
- Enlace al repositorio y a la demo publicada.
- Conocimientos adquiridos y mejoras futuras.

### 4. Seguimiento del aprendizaje

Los usuarios podrán relacionar cada proyecto con los módulos, cursos y conceptos que aplicaron durante su desarrollo.

También podrán registrar las actividades realizadas y el tiempo dedicado a cada proyecto.

### 5. Resúmenes asistidos por inteligencia artificial

La plataforma podrá generar resúmenes estructurados a partir de la información registrada por el estudiante.

Estos resúmenes podrán incluir:

- Objetivo y descripción del proyecto.
- Tecnologías utilizadas.
- Conceptos técnicos aplicados.
- Módulos formativos relacionados.
- Dificultades y soluciones documentadas.
- Principales aprendizajes.

El tiempo de dedicación se calculará a partir de los registros del usuario. La IA redactará el resumen utilizando esos datos, sin inventar horas ni competencias.

Los resúmenes deberán poder revisarse y editarse antes de su publicación.

## 🧰 Stack tecnológico

El proyecto se desarrollará progresivamente utilizando las siguientes tecnologías:

| Área                     | Tecnologías                   |
| ------------------------ | ----------------------------- |
| Estructura web           | HTML5                         |
| Estilos                  | CSS3, SCSS                    |
| Programación frontend    | JavaScript, TypeScript        |
| Framework principal      | Angular                       |
| Framework complementario | React                         |
| Backend principal        | Java, Spring Boot             |
| Backend complementario   | Node.js                       |
| API                      | REST, HTTP, JSON              |
| Base de datos            | PostgreSQL                    |
| Persistencia Java        | Spring Data JPA               |
| Control de versiones     | Git, GitHub                   |
| Pruebas de API           | Postman                       |
| Inteligencia artificial  | API de modelos de lenguaje    |
| Gestión del desarrollo   | Issues, ramas y Pull Requests |

**Nota:** Las tecnologías se incorporarán por etapas. Java con Spring Boot será el backend principal de la aplicación; Node.js se utilizará como tecnología complementaria de aprendizaje. React se explorará mediante ejercicios adicionales si el alcance y el ritmo del proyecto lo permiten.
